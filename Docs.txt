# DocReplacer: Official Documentation

**The fastest, most secure way to generate professional `.docx` files from a single prompt.**

---

## **Introduction**
DocReplacer is a utility-first web application designed to instantly transform simple text prompts into fully formatted, ready-to-download Microsoft Word (`.docx`) documents. 

Built with privacy and efficiency in mind, DocReplacer operates entirely on the client side. By converting AI-generated JSON payloads directly into valid XML structures and compressing them locally within your browser, it eliminates the need for backend servers. Your data remains completely private, and your inputs are never stored or used to train AI models.

---

## **How DocReplacer Works**

DocReplacer simplifies document creation into a seamless three-step workflow:

### **1. Describe (Prompt & Configuration)**
Start by providing a single prompt describing the document you need. You have full control over the initial structure:
* **Document Type:** Choose the appropriate tone—Professional, Academic, Technical, Business, or Report.
* **Target Length:** Select anywhere from 1 to 10 pages. The system automatically calculates the necessary sections and word counts.
* **Smart Outlining:** The AI analyzes your prompt and generates a precise document outline, ensuring logical flow from introduction to conclusion.

### **2. Review & Edit (The Template Editor)**
Before generating the final file, DocReplacer presents your content in an interactive block-based editor. 
* **Block Management:** Reorder sections using up/down arrows, delete unnecessary blocks, or manually type in edits.
* **Surgical AI Edits:** Click the **✦ AI** button on any specific block (like a paragraph, table, or bullet list) to rewrite, expand, or format that exact section without regenerating the entire document.
* **Global Style Settings:** Customize the look of your document before downloading. Adjust font families (e.g., Arial, Times New Roman), font sizes, text and background colors, line spacing, bullet styles, and precise page margins.

### **3. Done (Preview & Download)**
Once you are satisfied with the content and styling:
* **In-Browser Preview:** View a high-fidelity preview of your document directly in the browser to ensure formatting is perfect.
* **Instant `.docx` Assembly:** The app uses local compression to package your content into a standard `.docx` file in seconds.
* **Download:** Save the file straight to your local machine.

---

## **Key Features & Capabilities**

* **100% Client-Side Architecture:** The conversion from JSON to XML and the final `.docx` compression happen entirely within your local browser environment. 
* **No-Training API Guarantee:** DocReplacer focuses on document assembly. It utilizes models for text generation without logging your prompts or utilizing your private data for model training.
* **Rich Document Structures:** The engine supports a wide variety of document elements, including:
    * Titles, H1, and H2 Headings
    * Rich-text paragraphs (supporting bold, italic, and hyperlinks)
    * Structured Tables (with customizable header backgrounds and row shading)
    * Bullet-point lists (with customizable symbols and indents)
    * Multi-column layouts
* **Dynamic Data Tables:** The AI generates specific, context-aware tables (never generic placeholders) that you can manually add rows to, delete from, or edit directly in the interface.

## **Frequently Asked Questions (FAQ)**

**Is my data sent to a server for document creation?**
No. DocReplacer is a fully client-side application. While the text is generated via an AI endpoint, the actual construction, formatting, and zipping of the `.docx` file happens locally on your device. 

**Can I change the formatting of the generated document?**
Yes. The Global Style Settings menu allows you to adjust font families, text sizes, alignments, line spacing, margin sizes (Normal, Narrow, Moderate, Wide), and table aesthetics before you build the file.

**Will the `.docx` file work in standard word processors?**
Absolutely. DocReplacer surgically builds valid Open XML documents (`word/document.xml`), ensuring 100% compatibility with Microsoft Word, Google Docs, and LibreOffice without breaking layouts.

**Do I need an account to use DocReplacer?**
No. DocReplacer is built on a utility-first model. There are no complex onboarding steps—just open the app, enter your prompt, and generate your file.
